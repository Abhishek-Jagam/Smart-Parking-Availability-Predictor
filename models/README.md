# Pre-Trained Model Directory

The serialized model artifacts (`parking_model.joblib` and `model_metadata.joblib`) are generated by running Cell 10 of `notebooks/Smart_Parking_Predictor.ipynb`.

To generate them locally:
```bash
python notebooks/Smart_Parking_Predictor_Colab.py
```
This keeps the GitHub repository lightweight and compliant with repository size guidelines.
